# Radar Zamora

MVP navegable para validar un radar de oportunidades comerciales dirigido a proveedores de Zamora Chinchipe.

## Alcance actual

- Oportunidades de demostración con búsqueda, filtros y ordenamiento.
- Puntaje de compatibilidad calculado con el perfil del proveedor.
- Detalle con requisitos, fechas y explicación del puntaje.
- Favoritos, perfil y preferencias guardados en el navegador.
- Diseño adaptable para escritorio y celular.

Los procesos incluidos son datos ficticios para validar la experiencia. La integración con fuentes oficiales y alertas de WhatsApp corresponde a una fase posterior.

## Ejecutar localmente

Sirve la carpeta `dist` con cualquier servidor estático. Por ejemplo:

```bash
python -m http.server 8000 --directory dist
```

Luego abre `http://localhost:8000`.
